# Skill 2 – Mini Shell

## Aim

To implement a simple shell program in C that accepts commands and demonstrates command processing and input handling.

## Description

The program implements a basic shell called `myShell`. It accepts user input and supports `hello`, `help`, and `exit` commands. Unknown commands are also handled.

## Commands Supported

- `hello` – Displays a greeting.
- `help` – Displays available commands.
- `exit` – Exits the shell.
- Other commands – Displays an unknown command message.
